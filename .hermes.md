# GangNiaga AI OS — Workspace Context for Hermes-Agent

This file defines the project boundaries, API interfaces, database schema, and coding guidelines for the GangNiaga AI OS workspace.

---

## 🏗️ Architecture Overview
GangNiaga AI OS is a multi-agent business OS tailored for ASEAN SMEs. It runs on a dual-database stack:
* **Development:** Local SQLite via Prisma.
* **Production:** Supabase PostgreSQL.

### Key Directories
* `src/app/api/`: Next.js App Router API endpoints.
* `src/components/modules/`: Individual feature consoles (OpenClaw, MCP, Financials, Dashboard).
* `src/lib/`: Library modules (ai-provider, db, supabase, hermes client, mcp manager).
* `skills/`: Standard agent skills formatted as `SKILL.md`.

---

## 🌐 API Interfaces & Core Endpoints

* **Sembang Ejen (Chat Proxy):** `/api/chat` (Proxies directly to Hermes Agent using `src/lib/hermes.ts`).
* **MCP Controller:** `/api/mcp` (GET to list servers, POST to connect, discover, and execute tool calls).
* **OpenClaw Gateway:** `/api/openclaw/gateway` (Gateway for Telegram/WhatsApp bot routing).
* **Copilot Tools:** `/api/copilot/tools` (Safe file reading/searching utilizing `execFileSync`).

---

## 🗄️ Database Schema & Optimization Rules

* **Tenancy:** Every model must be filtered by `organizationId`.
* **Indexing:** All querying foreign keys (like `organizationId` and `sessionId`) are indexed using `@@index`.
* **Cascade rules:** Parent deletion (`Organization`) cascades and cleans up child rows (`onDelete: Cascade`).
